# carminelatorraca.github.io

Personal site for Carmine La Torraca — Software & RPA Developer.

A single static page (`index.html`, plain HTML/CSS/JS, no build step), deployed
to GitHub Pages via `.github/workflows/deploy.yml` on every push to `main`.

## Structure

- `index.html` — the whole site
- `assets/img/` — avatar and project images
- `assets/pdf/` — downloadable CV

## Local preview

Just open `index.html` in a browser, or serve the folder with any static
file server, e.g.:

```sh
python3 -m http.server
```
